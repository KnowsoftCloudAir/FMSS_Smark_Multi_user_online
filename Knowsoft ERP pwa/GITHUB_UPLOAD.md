# GitHub upload checklist

1. Extract this ZIP.
2. Copy the contents into the FMSS project public/static directory.
3. Commit the files.
4. Deploy/redeploy the application.
5. Open the site over HTTPS.
6. Verify the browser shows the Knowsoft ERP icon and that "Install app" is available.
7. Test the app in a private/incognito window and on a mobile device.
